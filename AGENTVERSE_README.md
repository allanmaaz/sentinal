SentinelFlow is an autonomous cybersecurity multi-agent swarm built on **Fetch.ai uAgents** and the **Agent Chat Protocol (ACP)**. ## What SentinelFlow Does

1. **Instant Account Scans (Free):** Ingests and analyzes recent authentication logs to identify credential guessing, impossible travel, and unauthorized sessions.
2. **1-Tap Emergency Containment (0.1 FET):** Instantly revokes OAuth refresh tokens, deletes active session cookies, and quarantines attacker IP addresses at the firewall.
3. **Cryptographic Proof (SHA-256):** Our independent Auditor Agent inspects the post-action state (`active_sessions == 0`) and generates an immutable digital safety certificate.
4. **Natural Language Interface:** Talk in plain English or use 1-tap interactive cards. No security expertise required.

* **Investigator Agent:** Executes deterministic log retrieval and neutralizes indirect prompt injections.
